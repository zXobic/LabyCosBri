# LabyCos

### English

A client mod for displaying LabyMod cosmetics without the LabyMod client. Dynamically loads geo, animation, textures and colors via API. Cape &amp; wings working. Learning project, not affiliated with Laby.


### Deutsch

Ein Client-Mod zum Anzeigen von LabyMod-Cosmetics ohne LabyMod-Client. Dynamisches Laden von geo, animation, Texturen und Farben über die API. Cape & Flügel funktionsfähig. Lernprojekt, nicht mit Laby verbunden
